# 3.2.0

GUI（computer use）なしでゲインステージングを行えるようにするマイナーリリース。公開 MCP ツールは引き続き `meta` / `do` / `render` / `undo` の 4 つ。既存の機能は後方互換。

## 変更内容

### レベル解析（VU / PEAK）

- `render` の artifact 解析に **RMS dBFS（VU 相当）** と **sample peak dBFS** を追加し、`audio` と `manifest.json` に記録する。`source:"main"` と Pre-FX の双方に適用。
- WAV（PCM 16/24/32、float 32/64）と AIFF（PCM 16/24/32）のサンプルをデコードして算出する。無音は `null` とし、`all samples are silent` の警告を返す。
- true peak（オーバーサンプリング）と LUFS は本版の対象外。

### Meter 仮想ノード

- AbletonOSC の `output_meter_level` / `output_meter_left` / `output_meter_right` を `MATCH (m:Meter) RETURN m.trackIndex, m.trackName, m.level, m.left, m.right` で公開する（通常トラックのみ、`level` は 0..1 のリニア値）。OSC 未接続時は 0 行。

### ゲインステージング手続き（限定 CALL）

- `CALL gainstage.measure("<trackName>", <beats>)`: 再生してライブメーターを区間ポーリングし、VU(RMS)/PEAK を返す（再生位置・loop・punch は復旧）。
- `CALL gainstage.track("<trackName>", <targetDb>)`: トラック volume を目標へ収束。
- `CALL gainstage.device("<trackName>", "<deviceName>", <targetDb>)`: デバイスの Output/Gain/Volume を目標へ収束。
- `CALL gainstage.main("<vu|peak>", <targetDb>, <beats>)`: Main を捕捉して RMS(VU)/PEAK を測り、Main volume を目標へ収束。
- ミキサー volume は 0..1 の正規化値（dB 直ではない）ため、実測の傾き（dB/単位）から収束させる。上限反復回数・許容誤差・測定拍数は環境変数で制御。
- `preview:true` は OSC 送信なし、`confirm:true` 必須。Main 録音中は拒否。

### 集約・設定

- `meta` の `runtime` に `meter`（available / method / reason）と `gainstage`（available / metrics / targets / measureBeats / maxIterations / toleranceDb）を追加。
- 環境変数: `LIVE_CONNECTOR_GAINSTAGE_MEASURE_BEATS`（既定 8）、`LIVE_CONNECTOR_GAINSTAGE_MAX_ITERATIONS`（既定 4）、`LIVE_CONNECTOR_GAINSTAGE_TOLERANCE_DB`（既定 0.5）。
- エラーコード `GAINSTAGE_NOT_CONVERGED` を追加。収束しなかった場合は成功と偽らず `status:"not_converged"` と実測値・適用値を返す。

## 動作確認

- `pnpm typecheck`: 全 6 パッケージ成功
- `pnpm test`: 176 件全緑（cypher 85 / lom-schema 8 / extension 85）
- `pnpm lint`: Biome 成功
- 実機（Live 12.4.15b2 + AbletonOSC）: `Meter` 仮想ノードが通常トラック分を返すこと、`gainstage.*` の preview が副作用なしで通ることを確認。
- 実機の収束（トラック volume / デバイス Output / Main）は作業中 Set への影響を避けて保留。確認後に追記する。

## 制約

- トラック/デバイスの**ポストフェーダ**測定は AbletonOSC のトラックメーター（1 値、ピーク寄り）のみ。VU/PEAK を厳密に分けて測れるのは Main 捕捉（`gainstage.main`）経由。
- 測定は実時間再生を伴い、曲の内容に依存する。無音区間では収束できない（`GAINSTAGE_NOT_CONVERGED`）。
- AbletonOSC は Main（master）メーターを公開しないため、Main は捕捉解析で代替する。
- true peak・LUFS は未実装。

## インストール / 更新

- `pnpm package` で `apps/extension/dist/live-connector-3.2.0.ablx` を生成。
- ゲインステージングと Main 録音を使う場合は AbletonOSC と `LIVE_CONNECTOR_OSC_ENABLED=true` が必要。
