# 3.0.0

MCP ツール表面を 39 ツールから 4 ツール（meta / do / undo / render）へ全面統合したメジャーリリース。**破壊的変更**。

## 変更内容

### 4 ツール・タクソノミー

人間の操作タクソノミーに沿った 4 動詞:

| 動詞 | ツール | 役割 |
| --- | --- | --- |
| 入口 | `meta` | サービス情報、LOM スキーマ、do 文法契約、例文、時刻座標、仮想ラベル、Live Set overview |
| 見る・変える | `do` | Cypher 文による読み取り（MATCH … RETURN）と書き込み（SET / CREATE / DELETE / COPY） |
| 聴く | `render` | AudioTrack の Pre-FX オーディオレンダリング（同期または `background:true` ジョブ） |
| 戻す | `undo` | do 書き込みの逆操作を LIFO で適用（`steps` または `writeId`） |

### 旧ツール → 新表面（対応表）

| 旧ツール | 新表面 |

### Cypher 書き込み文（方言）

`parseStatement` が解釈する書き込み文:

- **SET**: `MATCH (n:Label {...}) SET n.prop = <value> [, n.prop2 = <value>]*`
- **CREATE**（standalone）: `CREATE (t:MidiTrack|AudioTrack {name?})` / `CREATE (s:Scene {index?, name?})` / `CREATE (c:CuePoint {time, name?})`
- **CREATE**（anchored）: `MATCH … CREATE (a)-[:REL]->(n:Label {prop: value})`（Device / Session Clip / Arrangement Clip / Note）
- **DELETE**: `MATCH … [DETACH] DELETE n`
- **COPY**: `MATCH … COPY n`（Track / Scene / Device）

### 応答・ガードレール

- 書き込み応答は**差分のみ**（`changed` / `created` / `deleted` / `copied`）。全オブジェクトの再列挙はしない。
- マッチ 0 件はエラーではなく `{status:"no_match", matched:0, hint}`。
- 全書き込みは **inverse diff** を undo ログへ記録し、`writeId` と `undoable`（`full` / `partial` / `none`）を宣言。
- `undoable` が `partial` / `none` の書き込みは `confirm:true` 必須（`confirmGate`）。`full` は即実行可。
- `preview:true` でドライラン（`status:"preview"` または `confirm_required`）。

### undo ログ

- 永続化: `environment.storageDirectory/undo/undo-log.jsonl`（JSONL、最大 200 件ローテーション）。
- 各エントリ: `writeId` / `time` / `statement` / `kind` / `summary` / `undoable` / `status` / `inverse[]`。
- `inverse` 種別: `set_properties` / `notes_replace` / `delete_created` / `recreate`（`RecreateBlueprint` による再作成）。
- `undo` ツールは LIFO（既定 `steps:1`）。undo 自体は新しい undo エントリを作らない。
- 照会: 仮想ラベル `WriteEvent`（`do` read）。

### 仮想ラベル

- **WriteEvent**: undo ログエントリ（読み取り専用）。`MATCH (e:WriteEvent) RETURN e`
- **RenderJob**: render 非同期ジョブ状態（読み取り専用、module singleton、最大 50 件）。`MATCH (j:RenderJob) RETURN j`
