## 変更内容

- `llm/models.yaml` の decisions に `tool_organization_132` を追加する。内容:
    - 設計原則 5 項（読み取りの query 集約 / 書き込みは select + 操作種別 / annotations・confirm ガードの粒度維持 / batch は手続き集約レイヤ / 互換性・一括更新）
    - 候補 A〜F の 4 項目比較（`reduction` / `zod_annotations` / `batch_history_snapshot` / `breaking_change`）と `verdict`
    - 採用方針: 次メジャーで A（set_properties 仮称、6 → 1）と D（edit_notes 仮称、2 → 1）を同梱し 39 → 33 件。B は #104 の `revisit_when`（45 件超）未到達、C は annotations が CREATE_WRITE / DESTRUCTIVE / IDEMPOTENT_WRITE の 3 区分にまたがり設計原則 3 と矛盾するため不採用
    - deprecation 期間は旧 8 + 新 2 の並行残置で一時 41 件（恒久超過ではなく削除完了で 33 件に着地）
    - ツール名変更時の一括更新チェックリスト 6 箇所と follow-up Issue 起票案 4 件
