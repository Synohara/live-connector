# 3.3.0

運用強化（設計書 §12 P5）。companion Remote Script による無人運用の保護、対象検証付き命令、heartbeat 停止、job 単位トークン付き artifact 提供を追加する。公開 MCP ツールは引き続き `meta` / `do` / `render` / `undo` の 4 つ。既存機能は後方互換。

> 本版は 3.2.0（VU/PEAK 計測とゲインステージング, PR #4）の次に位置づける。3.2.0 を先にマージする。

## 変更内容

### companion Remote Script（Live Python）

- リポジトリ同梱 `remote-scripts/live-connector-companion/`。AbletonOSC と同様に Remote Scripts として導入し、Control Surface に追加する。
- loopback TCP（既定 `127.0.0.1:11002`）+ JSON 行プロトコル（requestId / ACK / タイムアウト）。
- コマンド: `status` / `heartbeat` / `verify_track` / `watch` / `enforce_stop` / `events`。
- 役割: heartbeat 期限での transport 停止・`record_mode` off・録音トラック disarm・loop/punch/停止位置の復旧、録音範囲上限、対象トラック検証、Set epoch（トラック名の djb2）照合、停止後の安全化。Live crash の救済は対象外。

### 拡張側

- `apps/extension/src/companion/`（client / protocol / epoch）。activation 単位の singleton として Runtime が保持。
- Main 実行前に `verify_track` で対象トラックと Set epoch を検証し、不一致は `COMPANION_SET_MISMATCH` で中止。
- 録音中は heartbeat を送出し、終了時に watcher を無効化。companion 未接続でも従来機能は動作する（`meta` の `runtime.companion.connected:false` と理由）。

### artifact 提供

- 既存 loopback HTTP サーバーに `GET /api/v1/artifacts/<jobId>/<token>` を追加。job 単位の推測困難なトークンと TTL を持ち、任意パスは読めない。
- `render` の応答（Pre-FX 同期・非同期、Main）に `artifactUrl` を追加。job 単位トークンが無効化されると `role` に応じて 404 / 403 を返す。

### 設定・エラー

- 環境変数: `LIVE_CONNECTOR_COMPANION_ENABLED`（既定 false）/ `..._HOST` / `..._PORT` / `..._HEARTBEAT_MS`（既定 1000）/ `..._TIMEOUT_MS` / `..._STALE_MS`（既定 10000）/ `LIVE_CONNECTOR_ARTIFACT_DELIVERY_ENABLED`（既定 true）/ `LIVE_CONNECTOR_ARTIFACT_TOKEN_TTL_MS`。
- エラー: `COMPANION_UNAVAILABLE` / `COMPANION_SET_MISMATCH`、HTTP 403 用 `ForbiddenError`。

## 無人運用で保証できる範囲

- companion 導入時: 拡張プロセスが停止しても、Live が正常稼働していれば heartbeat 途絶から一定時間で transport 停止・録音終了・設定復旧を行う。
- 対象トラック検証と Set epoch 照合により、別 Set への誤操作を抑止する。
- 保証しない: Live 自体のクラッシュ/フリーズ、GUI・他クライアント・他 Remote Script の手動操作、OS 全体の停止。録音のサンプル精度や音質は別途検証。

## 制約

- companion は別途インストールが必要（未導入でも MCP 機能は動作）。
- TCP は loopback バインドのみ。認証は行わず、localhost 前提とする。
- artifact 配信は loopback クライアント向けで、トークンはログ・応答に含まれる点に注意する。

## インストール / 更新

- `pnpm package` で `apps/extension/dist/live-connector-3.3.0.ablx` を生成。
- 無人運用の保護を使う場合は companion Remote Script を Remote Scripts に配置し、`LIVE_CONNECTOR_COMPANION_ENABLED=true` を設定する（Live を環境変数付きで起動）。
